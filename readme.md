The goal of this project is to scrape my google email for warm introductions from my headhunter, and then follow up with both a generic 'pleased to meet you' email.  it also tries to find the same folks in linked-in, provides a url and the ability to send them a note asking for a connection.  the linked in send is not automatic, -- you have to validate each one with a yes or no

The central control is from an excel file that gets updated each time you run the code. if it sees a linked in profile without a yes or no, it starts with that one
